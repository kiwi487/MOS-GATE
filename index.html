Model / Reproducibility

How were these COMSOL results generated?

Simulation workflow

2D NMOS geometry→Semiconductor physics→Parameter sweep→Export results

The silicon NMOS is modeled in COMSOL Multiphysics 5.3, using the Semiconductor interface and a Thin Insulator Gate condition to represent the gate oxide.

After sweeping oxide thickness and gate bias, numerical values and 2D maps are exported, then linked to the sliders in this page. The HTML displays precomputed solutions; it does not solve the COMSOL model in real time.

Outputs include drain current, electron/hole sheet charge, surface potential and oxide-interface electric field. Ideal oxide capacitance is analytic; gm comes from numerical differentiation of ID–VG.

COMSOL source model: Application Libraries → Semiconductor Module → Devices → mosfet
Template: .../applications/Semiconductor_Module/Devices/mosfet.mph (actual installation directory varies).

↗ View COMSOL model report (HTML) ↗ Original COMSOL model (.mph) · Google Drive

The report records the current example study (5 nm and 0.5 V steps); website plots use the earlier finer 1 nm and 0.1 V COMSOL exports.

COMSOL data

All 1,586 combinations (26 thicknesses × 61 gate voltages) are included in this HTML. Charts use COMSOL results; only the ideal oxide capacitance is analytical. The four 2D map collections load automatically from the images folder after running organize_images.py.

Use the included organize_images.py script on your Image.zip file to create four sets of 1,586 COMSOL PNG frames (electron, hole, electric field and potential). The map switches automatically when images are present. You can override a frame by importing a PNG/JPG named like electron_tox_05_vg_-2.0.png, hole_tox_10_vg_0.5.png, field_tox_20_vg_4.0.png, or potential_tox_30_vg_2.0.png. You can also put the quantity and thickness in folders, for example electron/tox_05/vg_-2.0.png.

Load multiple files or select a whole parent folder. The Channel Charge sliders will then select the matching frame. Ordinary GIF animations can also be imported, but their internal frames cannot be indexed by gate voltage; untagged GIFs are shown only as a separate reference.

Presentation controls

Use normal scroll for reading. ↑ / ↓ and PageUp / PageDown jump between the five chapter anchors. Each thickness slider is independent. The Channel Charge slider spans VG = −2 to 4 V.

On the second chapter, the number and opacity of charge symbols respond gradually to the simulated electron sheet charge and hole-charge change. These are illustrative markers, not a physical count of carriers. The regime label beside Carrier distribution updates from the simulated sheet-charge trends when V_G or oxide thickness changes. It is qualitative, not an extracted threshold voltage.

The four map sequences can be installed with organize_images.py. If needed, use the hidden load controls in the HTML or the included image organizer to preview images without installing them. Use the two small Play buttons beside the Channel Charge sliders to loop either parameter while holding the other fixed. Enter seconds per step (default 0.1 s). The next eight nearby PNGs are prefetched and decoded. Playback waits for each image before advancing, and a persistent display surface prevents flashing. Clicking the active button again or operating other controls stops the loop. Extra manually loaded images must be re-selected after refreshing. Chapter 05 has four questions, immediate answer feedback, a direct summary shortcut, and a Restart button.
